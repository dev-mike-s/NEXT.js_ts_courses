# 02 React UI Models

UI-Models beschreiben, was die UI anzeigen soll.

Sie sind nuetzlich, wenn JSX sonst voll mit Feldlisten, Buttontexten, Statuslabels oder Konfigurationslogik wird.

## Was gehoert hier rein?

- Feldreihenfolge
- Labels
- Placeholder
- Buttontexte
- Anzeigezustaende
- einfache View-Models fuer Komponenten

## Was gehoert nicht hier rein?

- Datenbankzugriff
- Fetch direkt zur API
- Business-Entscheidungen mit Seiteneffekten
- grosse globale App-Konfiguration
