# 05 Pattern Library

Dieser Ordner ist dein zentraler Such- und Wiederverwendungsbereich fuer JS, TS, React, Next.js und Full-Stack-Patterns.

Er ist nicht wie ein Kurs sortiert, sondern wie eine Codebasis, in der du spaeter gezielt nach Loesungen suchst.

## Wann hier suchen?

- Du willst wissen, wohin ein Typ, DTO, Schema oder UI-Model gehoert.
- Du brauchst ein Beispiel fuer React-Komponenten mit Props, State oder Formularen.
- Du suchst ein Next.js App-Router-Pattern fuer Pages, Layouts, Route Handler oder Server Actions.
- Du willst Prisma/Postgres nicht direkt ueberall in Komponenten verstreuen.
- Du brauchst Test- oder Architektur-Beispiele.

## Ordner

- `01_typescript_contracts`: Types, DTOs, Zod-Schemas, Mapper.
- `02_react_ui_models`: UI-Models, Props-Design, View-Models, Komponenten-Konfiguration.
- `03_nextjs_app_router`: App Router, Route Handler, Server/Client Boundaries.
- `04_data_api_db`: API-Schicht, Prisma/Postgres, Repository-/Service-Ideen.
- `05_forms_validation`: Formulare, React Hook Form, Zod, Submit-State.
- `06_state_data_fetching`: Client-State, Serverdaten, Lade-/Fehlerzustaende.
- `07_testing_quality`: Tests, Testarten, Lint/Typecheck-Denken.
- `08_folder_architecture`: Ordnerstruktur, Feature-first vs Layer-first.
- `99_search_tags`: Suchbegriffe und mentale Landkarte.

## Weg 1 und Weg 2

Weg 1 ist dieser Ordner: kleine, klare Patterns zum Nachschlagen.

Weg 2 ist ein konkreter Prototyp wie `1_RETOURO_FORM_NEXTJS`: dort siehst du dieselben Ideen in einem echten Projektfluss.

Mein Rat: Nutze `0_NEXT.JS_TS_COURSES/05_pattern_library` als Haupt-Lernplattform und echte Projekte nur als lebendige Beispiele.
