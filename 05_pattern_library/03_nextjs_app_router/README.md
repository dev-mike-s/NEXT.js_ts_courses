# 03 Next.js App Router

Hier sammelst du Beispiele fuer Next.js App Router.

## Typische Fragen

- Ist das eine Server Component oder Client Component?
- Wo validiere ich `params` und `searchParams`?
- Wann nutze ich Route Handler statt Server Action?
- Wo gehoert `notFound()` hin?
- Wo darf ich Prisma importieren?

## Merksatz

Serverdaten so weit oben wie moeglich laden.
Interaktion so klein wie moeglich in Client Components kapseln.
