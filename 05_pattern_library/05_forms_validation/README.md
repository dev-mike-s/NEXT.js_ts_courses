# 05 Forms Validation

Formulare verbinden viele Themen:

- UI-State
- Validierung
- DTOs
- API-Calls
- Fehlerzustaende
- Loading-State

## Reihenfolge, die sich bewaehrt

1. Zod-Schema bauen.
2. Type daraus ableiten.
3. Default Values definieren.
4. UI-Model fuer Feldreihenfolge bauen.
5. Submit-Funktion klein halten.
6. Fehler sichtbar machen.
