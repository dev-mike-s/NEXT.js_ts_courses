# Lektion 6 server actions und form handling

## Was ist das Programm in dieser Lektion?
Diese Lektion ist eine fokussierte Kata-Sammlung fuer das jeweilige Next.js-Thema.
Die Dateien bilden kleine, kombinierbare Bausteine, die du direkt in echten Projekten wiederverwenden kannst.

## Was ist das Learning?
Du lernst nicht nur Syntax, sondern Entscheidungslogik: wann welches Pattern sinnvoll ist,
wie TypeScript, React und Next.js zusammenspielen und wie du typische Fehler vermeidest.

## Dateiuebersicht
- `6.1-useActionState-vs-onsubmit.md`: Theorie- oder Referenzdokument, Learning: Lernt konzeptionelle Leitlinien fuer das jeweilige Thema
- `actions.ts`: Zentrale Server-Action-Funktionen, Learning: Lernt FormData-Mapping und typsichere Action-Contracts
- `serverActionForm.tsx`: Form action Pattern, Learning: Lernt direkte Bindung eines Formulars an eine Server Action
- `serverActionWithSubmitEvent.tsx`: Server Action via onSubmit Pattern, Learning: Lernt alternative Action-Ansteuerung mit eigener Formlogik
