# 6.1 useActionState vs onSubmit + FormData

## useActionState
- gut fuer server action status (`pending`, `error`, `success`) direkt im UI
- sehr passend fuer klassische Formular-Workflows mit enger React-Kopplung

## onSubmit + FormData + action(payload)
- gut wenn du Form-Parsing und Mapping bewusst selbst kontrollieren willst
- sehr transparent fuer komplexes Payload-Mapping oder mehrere Submit-Pfade

## Empfehlung
- einfache Form: `action={serverAction}` oder `useActionState`
- komplexe Formlogik: `onSubmit` + `FormData` + typsicheres DTO an Server Action
