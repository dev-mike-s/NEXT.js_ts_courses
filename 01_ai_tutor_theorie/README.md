# AI Tutor Theorie - Next.js Katas

## Was ist dieses Programm?
Dieses Verzeichnis ist ein vollstaendiges Self-Study-Programm fuer Next.js, TypeScript, JavaScript und React im Next.js-Kontext.
Der Fokus liegt auf praxisnahen Katas, damit du Loesungen im Projektalltag zuerst hier findest, bevor du extern recherchierst.

## Was ist das Learning ueber alle Lektionen?
- Architekturdenken fuer App Router und BFF
- saubere API- und Server-Action-Kommunikation
- Type-Sicherheit vom Input bis zur DB
- Security, Observability, Performance und Deploy-Readiness

## Lektionen (empfohlene Reihenfolge)
1. `lektion-1-setup-und-lernsystem`: Setup, Tooling, Lernmodus, Compiler-Hinweise.
2. `lektion-3-client-state-events-und-javascript`: React-Interaktion und JS-Grundmuster im Next.js-Kontext.
3. `lektion-9-typescript-patterns-fuer-nextjs`: Type-Sicherheit fuer Params, APIs, Actions und Validierung.
4. `lektion-2-routing-layout-und-navigation`: App-Router-Basics, Layouts, Navigation.
5. `lektion-4-datenfetching-caching-und-dynamic-routes`: Fetching, Revalidate, Segment-Strategien.
6. `lektion-5-api-route-handlers-und-node-runtime`: API-Design mit Route Handlers und Runtime-Wahl.
7. `lektion-6-server-actions-und-form-handling`: Server Actions mit `action=` und `onSubmit + FormData`.
8. `lektion-8-datenbanken-postgres-und-mongodb`: DB-Schnittstellen fuer PostgreSQL und MongoDB.
9. `lektion-7-auth-middleware-und-security`: Zugriffsschutz, Middleware und Cookie-Strategien.
10. `lektion-10-testing-und-deploy`: Testbasis, CI und Release-Checklisten.
11. `lektion-11-bff-und-api-orchestrierung`: BFF-Muster und Upstream-Aggregation.
12. `lektion-12-fehlerbehandlung-und-observability`: strukturierte Logs und robuste Fehlerpfade.
13. `lektion-13-performance-streaming-und-cache-strategie`: Suspense/Streaming und Cache-Tradeoffs.
14. `lektion-14-validierung-security-und-input-hygiene`: Input-Hardening und Security-Basics.
15. `lektion-15-webhooks-jobs-und-queue-grundlagen`: asynchrone Eventverarbeitung.
16. `lektion-16-architektur-und-modularisierung-im-nextjs-backend`: Skalierung per Service-/Repository-Architektur.

## Lernmodus-Empfehlung
- Jede Lektion lesen, dann Dateien lokal nachbauen, danach gezielt variieren.
- Bei Problemen zuerst innerhalb derselben Lektion vergleichen, dann zur naechsten Aufbaulektion gehen.
