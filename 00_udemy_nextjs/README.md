# 00_udemy_nextjs

Kurs-Workspace mit Vergleich zwischen Next.js 12 (Pages Router), Next.js 16 (App Router) und einer kleinen React-Basis-App.

## Projekte
- `next-app-v12`: Routing- und API-Grundlagen in Next.js 12
- `next-app-v16`: App-Router-Grundlagen, Route Handlers, TypeScript
- `next-project-v12`: Fullstack-Shop mit Pages Router, MongoDB, Redux, PayPal
- `next-project-v16`: Fullstack-Shop mit App Router, Middleware, Zustand, PayPal
- `react-app`: React-Grundlagenprojekt als Vergleichsbasis

## Start
Jedes Teilprojekt wird separat gestartet:
1. `cd <projektordner>`
2. `npm install`
3. `npm run dev` oder `npm start` (je nach Projekt)
