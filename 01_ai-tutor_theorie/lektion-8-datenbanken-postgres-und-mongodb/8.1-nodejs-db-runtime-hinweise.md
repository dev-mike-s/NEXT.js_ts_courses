# 8.1 Node.js Runtime Hinweise fuer DB-Access

- DB Treiber wie `pg`, `mongodb`, `mongoose` laufen typischerweise im Node.js Runtime-Modus stabil.
- Bei Route Handlers bei Bedarf explizit setzen:
```ts
export const runtime = "nodejs";
```
- Connections cachen, nicht pro Request neu aufbauen.
- ENV und Secrets niemals im Client Code verwenden.
