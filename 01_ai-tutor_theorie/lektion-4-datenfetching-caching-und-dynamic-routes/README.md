# Lektion 4 datenfetching caching und dynamic routes

## Was ist das Programm in dieser Lektion?
Diese Lektion ist eine fokussierte Kata-Sammlung fuer das jeweilige Next.js-Thema.
Die Dateien bilden kleine, kombinierbare Bausteine, die du direkt in echten Projekten wiederverwenden kannst.

## Was ist das Learning?
Du lernst nicht nur Syntax, sondern Entscheidungslogik: wann welches Pattern sinnvoll ist,
wie TypeScript, React und Next.js zusammenspielen und wie du typische Fehler vermeidest.

## Dateiuebersicht
- `4.1-nextjs-15-16-features.md`: Theorie- oder Referenzdokument, Learning: Lernt konzeptionelle Leitlinien fuer das jeweilige Thema
- `news.tsx`: Caching-Beispielroute mit Revalidate, Learning: Lernt Datenaktualisierung und Performance-Tradeoff
- `postDetail.tsx`: Dynamische Segmentseite, Learning: Lernt Params-Typing und Segment-Aufloesung
- `posts.tsx`: Serverseitiges Datenfetching, Learning: Lernt Fetch-Strategie und Revalidate-Grundmuster
